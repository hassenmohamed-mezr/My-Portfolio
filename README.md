# Hassen Mohamed — AI Engineer Portfolio

Personal portfolio website for **Hassen Mohamed**, focused on practical AI systems, RAG, machine learning, and AI-powered software integration.

## Featured work

- Egyptian Labor Law AI — retrieval-heavy RAG system
- Hospital Information System — healthcare operations platform with a dedicated AI service
- Breast Cancer Image Classification — classical machine learning and image preprocessing

## Tech stack

React, TypeScript, Vite, Tailwind CSS, Python/FastAPI architecture visualizations, and Lucide icons.

## Run locally

```bash
pnpm install
PORT=5173 BASE_PATH=/ pnpm --filter @workspace/hassen-portfolio run dev
```

Open `http://localhost:5173`.
